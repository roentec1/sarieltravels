Conexión con Google Sheets

Para que todo se administre desde Google Sheets:

  1. Crea un Spreadsheet con las hojas: CLIENTES, PROMOCIONES, DESTINOS, TESTIMONIOS, USUARIOS, CONFIGURACION
  2. Pega el código de google-apps-script/Code.gs en Apps Script
  3. Pon el ID del Spreadsheet en SPREADSHEET_ID
  4. Despliega como aplicación web (acceso: Cualquiera)
  5. Copia la URL .../exec y pégala en assets/js/api.js → propiedad URL
